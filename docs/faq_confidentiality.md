# FAQ — confidentiality

## Do you publish real project IFCs?
No. Real project IFC deliverables and owner documents are often contractually sensitive.

## What can be published openly?
- The executable pipeline code (this repo).
- Synthetic benchmark IFCs generated by scripts (`scripts/build_synthetic_benchmark.py`).
- Aggregated, anonymized outputs (e.g., pass rates by Depot_A/Depot_B, no filenames).

## Can I reproduce the paper figures without IFCs?
Yes, if you publish `file_level_outputs.csv` and `case_state_summary.csv`. The `figures` command can regenerate plots from those CSVs.
